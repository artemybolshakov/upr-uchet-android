# Упр. учёт

Android-приложение для управленческого учёта: задачи (Канбан, Гант, связи), CRM, календарь с напоминаниями-будильниками, заметки к встречам, текстовая сводка для мессенджера. Работает офлайн, данные хранятся на телефоне.

Адаптировано под Huawei Mate XT: сложенный, двойной и тройной режим экрана.

APK собирается автоматически GitHub Actions при каждом push в `main` и публикуется в Releases.

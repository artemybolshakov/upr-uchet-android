# Резервные копии: правила совместимости

Любая новая функция обязана сохранять возможность восстановить **любую** прошлую резервную копию.
Это проверяется автоматически: перед сборкой APK запускается `node tests/backup-compat.test.js`,
и если хотя бы одна копия из `tests/fixtures/` перестала восстанавливаться, сборка останавливается.

## Как устроено

- Формат данных, миграции и разбор копий — в `app/src/main/assets/schema.js` (без зависимостей от интерфейса).
- У данных есть номер схемы `SCHEMA`. У каждой копии он записан внутри.
- `migrate()` приводит данные любой версии к текущей; `parseBackup()` открывает файл копии любой версии.
- Неизвестные поля (например, из более новой версии приложения) не удаляются.

## Правила для новых функций

1. **Только добавлять.** Поля и коллекции не удаляются, не переименовываются и не меняют смысл.
   Если нужен новый формат поля — добавьте новое поле и продолжайте заполнять старое
   (пример: заметки хранят `html`, но и `body` — простой текст для поиска и старых версий).
2. **Изменили структуру — поднимите `SCHEMA` на 1** и добавьте функцию `MIGRATIONS[старая_версия]`.
3. **Миграции идемпотентны:** повторный прогон `migrate()` ничего не меняет.
4. **Ссылки между записями** (задача → проект, задача → контакт, ответственный проекта → исполнитель) при отсутствии цели сбрасываются, а не ломают экран.
   Узлы «Карт ответственных» с битой ссылкой (человек или проект удалён) убираются, их дочерние узлы поднимаются к родителю (`pruneMaps`).
5. **Положите копию новой версии** в `tests/fixtures/backup-vN-app-X.Y.Z.json`
   (Настройки → «Сохранить в файл» на тестовых данных). Тест требует копию текущей схемы.
6. Старые файлы из `tests/fixtures/` **никогда не удаляются и не правятся**.

## Что делает приложение при восстановлении

- Перед восстановлением автоматически делается страховочная копия текущих данных.
- Копия из более новой версии приложения открывается с предупреждением; неизвестные данные сохраняются.
- Повреждённая копия не применяется — текущие данные остаются нетронутыми.

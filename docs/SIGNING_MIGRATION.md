# Упр. учёт

Android-приложение для управленческого учёта: задачи (Канбан, Гант, связи), CRM, календарь с напоминаниями-будильниками, заметки к встречам, текстовая сводка для мессенджера. Работает офлайн, данные хранятся на телефоне.

Адаптировано под Huawei Mate XT: сложенный, двойной и тройной режим экрана.

## Установка версии 2

Версия 2 устанавливается как отдельное приложение с идентификатором `com.artemiy.uprucheet.v2`, рядом с прежней версией. Перед установкой экспортируйте JSON-копию данных из старого приложения, затем импортируйте её в новую версию. Не удаляйте старое приложение, пока не проверите восстановление данных.

Старая подпись приложения была раскрыта в публичном репозитории. Новые сборки подписываются отдельным ключом, который хранится только в GitHub Actions Secrets. Настройка описана в [руководстве по миграции подписи](docs/SIGNING_MIGRATION.md).

APK собирается GitHub Actions при каждом push в `main` и публикуется в Releases.
